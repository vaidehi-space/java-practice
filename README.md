# Java Practice
This repository contains the program I built while learning Java.
## Why I made this repository ?
I tried learning C++, Python and C mainly through one-shot tutorials.

While watching the tutorials, everything seemed to make sense. But when I tried to write even a basic program on my own, I couldn't.

So, when I decided to learn Java, I tried a different approach.

Instead of following tutorials that walked me through every program, I started only with the syntax and concepts I needed and tried to implement them myself.

When I got stuck, I looked up the logic, not the code and then I tried to implement it on my own.

I made mistakes, debugged them and tried again.

This repository was built to keep a record of that process.

## Learning Approach
**Learn → Implement → Get stuck → Research → Debug → Try again**

My goal wasn't to simply collect programs, but to become comfortable writing code and building logic independently.
